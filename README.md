# 井字過三關

立體動畫的井字過三關。兩人在九宮格輪流落下金叉與玉環，橫、直、斜先連成三子即勝一關；三關裡先勝兩關的一方過關。

## 玩法

- **人機**：初學、進階、宗師。宗師用完整搜索，經典棋路不會輸。
- **同機**：同一畫面輪流落子。
- **連線**：一人開設房間，把四位密碼或連結交給另一個畫面加入。
- **經典**：下滿九格無人連線則和。
- **消子**：從第七子起，每落一子先撤去自己最舊的一子，盤上最多六子，然後才判斷連線。

拖曳旋轉棋盤，滾輪拉近。鍵盤上排 `1` 到 `9` 對應由遠到近的九宮。

## 開發

```bash
npm install
npm test
npm run dev
```

瀏覽器打開 `http://localhost:5173`。

上線前先建置：

```bash
npm run build
npm start
```
